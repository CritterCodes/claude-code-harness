# Friction log

**Kind:** planning. When the owner sends a message starting `friction:`, the session files it here — on the row of the
work it belongs to — with the date and their words. **No ceremony, no follow-up questions.** The point is that
annoyance costs the owner one sentence, so they actually report it.

Each row gets a verdict when the work is next touched: **keep · smooth · rethink**.

| Date | Where | What the owner said | Verdict | Fixed in |
|---|---|---|---|---|
| <YYYY-MM-DD> | <screen / flow> | *"<their words>"* | <smooth> | <commit> |
